# Exact two-piece zipcode geometry: outcome-blind feasibility

This is a separate metadata-only design, written before sequence-coverage calculation. It never trains or evaluates a localization predictor and does not change any current model/gate/freeze. No protected data, numerical feature matrix, outcome table or weight file is an input. The four namespaces preserve bytes with `* -text` attributes.

[Patel et al., 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3258965/), DOI10.1101/gad.177428.111, identifies the recognition pieces `CGGAC` and RNA `[AC]CA[CU]`, either linear order. Its Bioinformatics section uses `CGGAC-(N10–25)-[AC]CA[CU]` OR `[AC]CA[CU]-(N10–25)-CGGAC`: 10–25 **strictly intervening** bases inclusive, not distance between starts or centers. The lower and upper limits were supported by binding experiments; 25 is a prediction cutoff, not proof that every longer spacer forbids binding. [Chao et al., 2010](https://pmc.ncbi.nlm.nih.gov/articles/PMC2807350/) establishes the KH3/KH4 geometry. The DNA representation maps U to T without reverse-complement scanning: both linear orders on the expressed strand are different from reversing/complementing the RNA.

`artifacts/generalization_zipcode_geometry_20261007/design.json` fixes the rule, controls and support definitions. Enumerate all overlapping recognition-piece starts and each valid pair once. A pair identity is its order and both zero-based starts. Count WT and mutant presence separately; record gained/lost pairs, count delta and turnover even if net count is zero. For equal-length substitutions every changed pair must contact an edited base in a recognized piece. Editing only the spacer changes neither recognition nor spacing in this exact rule; this is deliberately not a predicted structure/occupancy effect. Controls count isolated CGGAC, isolated `[AC]CA[CT]`, and the previous ACACCC proxy.

The only cohort sources are NEXT's already certified `sequence_inventory.csv.gz` and `encoded_sequence_inventory.csv.gz`, with exact six-column schema: intervention_id, dataset, biological_component, parent_context_id, parent_sequence, mutant_sequence. Their pinned hashes must match the committed NEXT prefit manifest. Neither contains labels. IDs/order and metadata must match exactly across inventories. Encoded contexts change only SRLE from six-base insert to certified46-base local arms+insert; all other parent/mutant bytes must be identical. SRLE local junction support is explicitly different from a native/full HBB transcript. Do not infer uncaptured transcript processing.

The design freeze binds source, tests, this protocol, fixed JSON, four byte attributes, source-inventory hashes and exact committed NEXT manifest. It is created before coverage and must be committed by the parent before execution. Coverage then emits row-level sequence-only summaries and equally descriptive assay/context/biological-component counts for original and encoded inputs. No numeric coverage threshold is selected, no favorable gene/assay is used to alter the rule, and no inferential confidence interval or pass gate is applied. In Mikl, the inherited biological components are certified whole-gene units; for other assays they are conservative biological components, not automatically unique gene symbols. Report source counts and the supplied independent units, without inventing gene identifiers.

Historical duplicate audit: Mechanism-v3 already counts the isolated ACACCC beta-actin proxy (`configs/mechanism_v3/grammar_design.json`) with an additive motif-count scorer (`src/mechanism_v3/grammar.py`). Source/config searches must include literal pieces and geometry, not only the word zipcode. No explicit CGGAC-plus-second-piece10–25 spacer implementation was found in the bounded source/config search. RBPNet/encoders may encode it implicitly; a future model would need matched single-piece/proxy controls and existing informative-feature contrasts. This new audit is a precise refinement of an established prior, not discovery of the zipcode mechanism. Earlier global+cell residual and expression-interaction models also already exist and are not new routes.

Meaningful synthetic tests cover exact spacer boundaries in both orders, all alternative second-piece alleles, overlapping occurrence enumeration, no-change and allele-reversal deltas, spacer-only mutation invariance, motif-pair turnover with zero net count, edited-piece contact and phenotype/schema rejection. They use only invented sequences and standard-library code. Running this scoped module is permitted; unfiltered pytest is not.

If paired geometry is sparse, report the exact independent-unit support and defer broad modeling. A future test would retain full original menus, freeze any estimator/objective beforehand and never choose an assay/spacing from its localization effects. Binding motif presence, observed RNA localization and a causal IGF2BP1-mediated effect are distinct claims. Missing protein/cell state and reporter context remain limits even if a predictive experiment later passes.
