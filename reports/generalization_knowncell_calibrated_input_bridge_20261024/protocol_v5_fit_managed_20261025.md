# Separate V5 managed-fit binding path

Only the immutable fit static-binding path changes from V3/V4. The complete
scientific validation function is AST-identical to V3; all schemas, admission
hashes, label/array bits, current-owner requirements and stable runtime
identity remain unchanged. The V3 and V4 bindings are preserved. No execution,
new attempt, native runtime import or retry authority is provided by V5.
