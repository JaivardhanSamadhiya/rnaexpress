# Calibrated supplied-input bridge

This small additive library validates objects already supplied by a separately
reviewed, actually owned prefit/FIT/replay/evaluation caller. It reads no CORE or
NPZ, bootstraps no runtime, invokes no sampler/pool/model/evaluation, and writes
no actual input admission or prefit. Original source and all scientific values,
rows, masks, sampler/configuration/scaling/scorer definitions remain unchanged.

The original bridge's actual guard, committed-byte, strict JSON, runtime-proof
schema and engine bit-hash helpers are reused. Guards can be changed only by
the approved real five-alias resource context in the reviewed owned caller.
There is no public guard/probe/common injection, and this library installs no
aliases. Without such a context the original guard still enforces its original
floor. A matching proof dictionary is not independently proof of current Job
ownership or native origins: the caller must perform those actual checks first.
The bridge explicitly returns that it did not certify them or grant authority.

Each stage has its own future fixed-path `root_bindings_<stage>.json`, whose
supplied bytes must be exact current committed bytes. The binding fixes actual
metadata/array/label certificate hashes, stable admitted array-after runtime
binding, new bridge readiness, reviewed controller/admission/birth and separate
current-stage fresh proof SHA. The future caller must verify its source and
admission closure, actual parent Job and approved policy before invocation.
No actual root binding is manufactured by preparation or tests. No label
certificate SHA is invented before actual label production.

The original actual array certificate is fixed to
`8d8d39763b6c9fc226ba7f616fe891dad37556ac83694d39f10667c24aefb9fa`.
Its supplied native float64 ndarray is returned unchanged. The bridge uses only
its original C-order bytes, finite scalar inspection and exact admitted
post-astype byte SHA. It does not call `np.array`, `astype`, change precision or
replace the frozen NPZ/astype admission process. A later owned caller may
narrowly reload the same frozen NPZ with the already admitted semantics.

Labels are the new calibrated original-pandas certificate. Its protected
`labels_result` contains all and only the unchanged original parser fields,
with the original ndarray's persisted `.tolist()` JSON float list. Require full
original ID/order, finite Python floats, original parser/orientation, and exact
`struct.pack('<d', value)` SHA. Signed zero and subnormal bits are preserved.
No reparse, alternate float conversion, rank/label recomputation or access to
other CORE columns is used. The bridge's label admission hash names this new
exact certificate, not a nonexistent replacement of the old loader manifest.

Calibration provenance must truthfully state generic resource exception true,
original guards false, unchanged scientific settings and exact approved
policy/AUTH/scope. The top-level actual CORE read receipt and protected
before/after label runtime proofs are checked without rewriting them. The
operational protected-proof hash uses the original operational pretty JSON
canonicalization; stable array-after runtime and engine shape/bit hashes use
the original bridge's compact canonicalization. These hashes are not exchanged.

The current-stage proof has a new fixed schema:
`PASS_FRESH_CURRENT_RUNTIME_ORIGINS_FOR_KNOWNCELL_STAGE`, its actual stage,
phase `before_supplied_input_bridge`, current/parent PIDs, caller birth and
reviewed controller admission, stable runtime anchor and exact software identity.
It records current UTC and a separate hash. A future reviewed stage provider
must produce it only after actual origin checks. The bridge compares its schema,
hash and current process IDs but does not itself enumerate DLLs or verify a
parent Job. Different current dynamic proofs need not equal the historic
array-after proof; the prefit/engine runtime binding remains the admitted anchor.

The output retains original engine metadata/features/effects/admission keys and
exact scalar-bit hash conventions. `effects` is only the original ordered
ID-to-persisted-float mapping. No output asserts FIT permission. Root must review
and commit source readiness, actual bindings and the actual owned controller
before use. Preparation and tests use invented arrays/metadata/float lists and
private mocks of real IO guards only; no actual scientific/runtime call occurs.
