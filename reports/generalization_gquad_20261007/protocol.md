# GQ arrangement and global folding-potential development experiment

This is a separately declared subsequent computational follow-up after exposed generalization and fixed endpoint-alignment experiments. It tests whether a known G-quadruplex folding prior adds useful held-assay candidate-edit ranking information to raw G-rich arrangements and existing ordinary-structure features. No first-GQ-method, unseen independent confirmation, in-cell occupancy or causal-mechanism claim is allowed. Prior studies already used G-rich motif/run features and establish neuronal GQ examples; they do not establish generalization across these four endpoints. Preparation reads sequence identities, provenance receipts and file hashes only. Root must review and commit a separate production freeze before project extraction and a separate prefit freeze before label-based fitting.
