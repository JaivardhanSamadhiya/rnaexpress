# Auxiliary empirical RNA-binding resource admission

Lee et al., *Nucleic Acids Research*2024, MPRNA-IP, DOI10.1093/nar/gkae334, publicly deposits designed oligonucleotide sequences and IP/input counts for PUM2, MS2-MCP, hTR-TERT and CTCF experiments. [Primary paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC11162807/), [NCBI GEO](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE221537), [author code release](https://zenodo.org/records/10633325).

This is a possible empirical auxiliary supervision source for sequence/structure-to-protein interaction. It is a different endpoint and cannot confirm RNA-localization edit ranking. The pools contain a small number of independent RNA designs, many molecular barcodes, and mixed truncations/multibase substitutions/compensatory mutations. Barcode multiplicity must never be counted as independent biological designs. Exact small-edit pairs, replicate/condition identity, source design sequences, original processing and overlap with localization source alleles must be audited before any training protocol is proposed.

The official NCBI public supplement listing includes five gzip sequence pools and five gzip count tables. The author-linked Zenodo API identifies a4,043,879-byte versioned code ZIP underCC BY4.0 with publishedMD5. Acquire only these11 fixed public files with bounded reads, exact URL/host verification, raw SHA256 and exclusive response receipts. Verify the author's size andMD5 for theZIP and archive/gzip integrity. Read scripts only as data; do not execute them. No fees or credentials are required. The article isCC BY-NC4.0; the explicit code license is separate, and no blanket GEO license is inferred from it.

Acquisition permits no model fitting, source reinterpretation of localization outcomes, protected table access, or claims of mechanism novelty. Binding outcomes are not untouched localization validation. A later auxiliary model needs a separately frozen protocol and realistic protein/cell/RNA-domain transfer controls. If designs or conditions are insufficient, retain the resource as deferred rather than inventing parents or endpoints.
