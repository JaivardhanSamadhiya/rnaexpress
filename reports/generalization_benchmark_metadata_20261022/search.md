# Bounded independent-benchmark metadata search

22 October2026 local. A literature agent searched primary sources; root independently checked the four identities below through PubMed/PMC/publisher queries. Some direct pages returned browser checks or empty extraction, so the verified primary search records/abstracts support identity and broad assay scope. No sequence, count, supplementary outcome, checkpoint or new benchmark payload was downloaded or admitted. This is a bounded search, not proof that no suitable dataset exists.

No newly qualified multi-gene, multi-context benchmark for ranking1–6nt localization edits emerged. Admission would still require exact parent/edit ancestry, context separation, construct-level outcomes and replicate provenance, public/free source verification, a locked candidate roster and an untouched evaluation protocol.
