This note proposes a subsequent observed-development experiment, not production or fitting authorization. No project sequences, features, labels, models, checkpoint/head tensors or predictions were read or computed for this audit. Only source, protocols, successful-backend metadata and runtime directory names were inspected. The native masked-MLM backend remains a separate prerequisite; metadata/mock PASS is insufficient. All earlier SpliceBERT/backend/downstream sources and results stay unchanged. No download, installation, spending, schedule or contact is needed.

## Quantity and historical cancellations

For a corresponding-coordinate edit with one through six changed sites, mask their entire union in both alleles. This gives one identical full token context. At each changed site use the unchanged author head's alternate-minus-reference logit, and sum these differences into scalar S. The identical ten-token log-softmax denominator cancels at each site, so direct logit subtraction implements the conditional log-ratio without subtracting large normalizers. This is a block-masked conditional marginal surrogate; the hidden sites are simultaneously unobserved, so its sum is not a jointly normalized multivariant probability or full pseudolikelihood.

The old [v2 failure analysis](D:/rnaexpress/reports/v2_failure_analysis.md) identified a genuine mathematical cancellation: a parent-only scalar c(parent) appended to a linear pairwise model contributes c(parent)−c(parent)=0 for two candidate edits. A parent-constant likelihood, confidence or occupancy prior would have the same problem and receive a zero unsupported coefficient under the current pair-RMS fitter. Adding it alone cannot repair conditional edit ranking. Interactions or variant-dependent quantities can survive the comparison.

S(parent,edit_i) need not be parent-constant: different edit sites change the masked context and different alternatives change the readout even under the same mask. The sampled ranking term is S_i−S_j. Merely writing an absolute-sequence score as score(mutant_i)−score(parent) also does not remove its varying mutant term: the common parent contribution cancels, leaving score(mutant_i)−score(mutant_j). This observation does not prove contextual information or usefulness. An additive base-composition score can reduce entirely to the already present substitution features.

Here an exact composition-only component is B=Σ_i(b_alt−b_ref), using the certified author MLM decoder bias. From [cross-assay feature source](D:/rnaexpress/src/cross_assay_20260927/features.py), the corrected 246-column base contains raw A/C/G/T mutant-minus-parent counts, so B is exactly a fixed linear combination of existing columns. Its intervention-delta space has at most three base-composition degrees of freedom; B itself is one scalar. Adding B therefore supplies no new unregularized linear information, but can change the effective L2 geometry. Use it as a same-width additional-column control, not a useful new biological feature. It does not fully match the contextual scalar's covariance/effective rank or every context-free tendency of the encoder.

Do not append S and −S together, or fit both as separate orientation candidates. For an unconstrained linear L2 head, replacing S by −S maps its coefficient β to −β and leaves the objective/predictions unchanged in exact arithmetic. Appending both duplicates a dimension and can weaken its effective penalty. Such tracks would not be distinct hypotheses. Also do not append a scalar formed as a linear combination of existing learned outputs and count it as new information. The old [v2.5 protocol](D:/rnaexpress/reports/v2_5_mikl_xgboost_transfer_preregistration.md) explicitly kept neurite-minus-soma score descriptive because the two separate head deltas already spanned it; its old protected-data evaluation is not revisited here.

## Orientation and matched downstream proposal

Positive S means the pretrained RNA model prefers an alternate nucleotide under the masked context. It does not mean more neurite, soma, nuclear, cytoplasmic or distal localization. There is no pretrained localization intervention head or validated zero-shot polarity here. Use S with one fixed definition and learn its coefficient/sign only from permitted source labels inside the existing nested folds. No held-assay outcome may select +S/−S, sum/mean, mask recipe, domain, head, layers or endpoint signs.

The narrow recommended test retains the original SpliceBERT downstream's **untransformed measured-effect policy** and original-truth evaluation. The fixed endpoint-aligned pipelines are separate follow-ups. Switching this proposal to that policy would require a new declaration and correspondingly aligned controls; unflipped checkpoints could not be reused as matched aligned controls. Applying a known endpoint backtransform is distinct from determining the statistical scalar's biological direction. An endpoint sign must never become an outcome-selected knob or an extra input here.

Recommend four fresh tracks, retaining original controls by exact verified reuse where admissible:

Do not add ordinary-structure/combined extensions, nonlinear readouts, alternative masking recipes, extra scalar transformations or a target-selected grid in this narrow first test. The original base246, lookup502 and splicebert502 are required comparators. If their finished downstream fits/verification become available and every source matrix, row order, label parser/bytes, source masks, original pair roster, solver/configuration/thread policy and prediction bytes can be certified, reuse their complete 40-checkpoint nested campaigns with independent arithmetic/config/choice replay. Reuse is not new independent evidence. Otherwise standalone baseline fits would be necessary and should be separately budgeted before freezing. No current model/prediction was opened to select this proposal.

For four new tracks, preserve four whole-assay outer folds and three source-held inner folds per outer, penalties .005/.05/.5 in original order, lowest source-only mean regret within1e−12 selecting first, original component/gene/exact-allele purges, cap256 sampled pairs, weighting, training-only pair-RMS and unsupported coefficients zero. This is4×40=160 new checkpoints, not160 additional biological tests. Source-learned orientation is automatic in the same fixed linear convex model. No encoder/head fine-tuning.

All inherited strict whole-assay thresholds and shared-component descriptive bootstrap must remain unchanged. Proposed base_masked must additionally gain≥.01 macro and positive leave-best-assay-out against original base, base_bias and original lookup. Proposed splice_masked must separately pass those same increments against original splicebert, splice_bias, base_masked and original lookup. The lookup comparator requires pretrained contextual information beyond the single-base lookup. Every declared new/control track must be reported. Passing is a narrow development result, not a novel method, independent confirmation or explanation of RNA localization. Additional-column controls constrain one regularization objection but do not prove capacity matching or mechanism.

## Remaining admission blockers and cost

The masked task count and requested-position coverage are unknown because no project inventory was read here; the unique context count is at most26,258. This plan is technically viable conditionally, with no new purchases/data requirements.
