# V1 preserved without execution

Two separate agents independently matched all 61 manifest pins and reviewed
the literal original resource floors and selective metadata scope. They found
three provenance issues before launch: the actual parent package initializer
was absent, the initially committed execution-manifest identity was not carried
through completion, and `-B` did not prevent existing cache reads. A final
process-handle sample was also needed for complete lifetime-peak reporting.

V1 was never started. The separate V2 namespace preserves every V1 source,
manifest and admission byte and addresses these findings. The existing metadata
admission is still metadata-only; no numerical label, array or fit is admitted.
