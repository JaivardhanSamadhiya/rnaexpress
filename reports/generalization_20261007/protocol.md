## Five routes and matched controls

1. **Scaling/regularization:** unchanged interaction_3 (246 columns), exact historical pair roster. Compare training-candidate weighted standard deviation and training-pair weighted RMS difference scaling. L2 penalties .005, .05, .5, in that order within candidate then pair scaling. Training-pair unsupported columns have zero coefficient. This diagnoses objective geometry; the audit has not established a software error.
2. **Ordered motifs:** append exact mutant-minus-parent 4-, 5- and 6-mer count differences (5,376 columns) to the same 246 columns. Sparse 5,622-column representation, same historical pairs and pair-RMS normalization. L2 .005, .05, .5. Sequence features do not read outcomes; no hashing, reverse-complementing RNA or outcome-selected motifs. Comparison with the pair-scaled short representation identifies the incremental information/capacity question.
3. **Literature-defined motif architecture:** same short representation plus fixed purine-clustering, C-rich/SIRLOIN arrangement and mutant-minus-parent/context products. Exact definitions are in frozen route_mechanism.py and the literature memo. Penalties .005, .05, .5; historical pairs and pair-RMS. These are proxies suggested by primary literature; fitted utility does not prove CNBP, HNRNPK or a localization mechanism. 5′TOP biology is excluded where only 3′UTR inserts are available.
4. **Coverage and robust source risk:** unchanged 246-column features, historical-pair .05 control, plus coverage-oriented pair sampling and either equal-source mean loss or a smooth maximum of source losses. For contexts with >256 possible pairs, form a deterministic random Hamiltonian chain over all candidates then uniformly top up distinct unordered pairs to min(all possible, max(2048,n−1)). Sampling is outcome-blind; exact training truth ties are then removed, so labeled coverage/connectivity is measured rather than guaranteed. Small contexts retain all pairs, as in the old roster. Each source, component and context is balanced. Pair-RMS scaling; .005, .05, .5 penalties for each coverage objective. Smooth maximum temperature is fixed at 5; it interpolates worst-source risk and does not prove extrapolation to unseen biology.

5. **Endpoint-conditioned transfer:** two separate source-trained utility heads for projection and nuclear/cytoplasmic enrichment, selected by the known requested endpoint at inference. Add exactly the 223 already-exposed, candidate-eligible SIRLOIN C replicate1/2 records to nuclear-head training only; no SIRLOIN confirmation outcomes are admitted. Both heads use original 246 interaction_3 columns, pair-RMS scaling and historical pairs; L2 .005, .05, .5. At every inner/outer fit, auxiliary rows sharing biological components or any exact allele with excluded core rows are purged. The nuclear source has only two parents/components; claims must retain that limited support. This route tests whether mixing known distinct endpoints and lack of nuclear source diversity weakened transfer. Endpoint identity is a declared biological input, not a fitted held-study label. Auxiliary rows are never counted as new independent confirmation or core evaluation rows.

All latent utility models optimize signed hard-preference logistic loss plus L2, zero initialization, L-BFGS-B max500, ftol1e-11, gtol1e-7. No intercept or source ID enters a candidate utility. Constant parent score shifts cancel. Features with no training pair support receive zero coefficient. Routes use exact source-only fitted normalization; source outcomes are never pooled in raw units. Larger libraries cannot dominate the macro objective. No priors, uncertainty constants, windows, seeds or formulas are tuned after outer results.

## Selection and evaluation

Whole-assay holdout is primary. Purge held biological components and exact alleles globally using the established outcome-blind groups and explicit allele check. Within each outer training pool, hold out each remaining assay in turn; fit every frozen configuration on the other source assays, purge globally, and select by mean of the inner assay macro normalized regrets. Ties within 1e-12 use configuration list order. Only that source-selected configuration is fit on all outer training data. No configuration is chosen using the outer assay. Single-component source folds are descriptive but retained. Five selected route outputs are compared; there is no target-specific sign flip or target-only calibration. Expected count is 284 fit checkpoints (76 scaling, 40 ordered, 40 mechanism, 88 coverage, 40 endpoint), including selected outer fits. Endpoint checkpoints contain two heads and therefore more than one optimizer invocation.

Select the highest utility for increasing the assay's admitted localization endpoint and lowest for decreasing it, lexical intervention ID breaking exact ties. Compute normalized regret, wrong direction, avoidable/unavoidable/neutral-alternative failures, feasibility, best and top-five recovery, tie-aware pair ordering. Average directions/context, biological component and assay equally. Store every candidate score and decision. Independently reconstruct the original H0 decisions from saved coefficients/scores before interpreting gains. Candidate utility is not an absolute localization effect or calibrated benefit probability; no new abstention claim is attempted.
