# Full outcome-blind conservation coordinate certification

This generation expands exact reference-coordinate coverage, not conservation scoring or predictive success. It preserves every 26,258 original intervention identity and every full parent-context menu in the admitted NEXT inventory, including every unmapped or ambiguous case. There are 3,022 exact parent identities. Source fields are restricted to the six committed original sequence/identity inventory columns, the four named canonical identity columns, and previously certified author FASTA/header/parent metadata. CSV identity projection interprets and retains only its declared columns; it does not construct or inspect outcome dictionaries. No effect, replicate, model, feature matrix, protected outcome or conservation value is accessed. There is no fitting, experiment selection, paid resource or scheduled task.

## Audit and preserved pilot

Before expansion, a new standard-library replay audits all 13 preserved pilot parents, 5,701 original pilot rows, 17 transcript-match vectors and 1,268 edited-site records against cached genomic DNA, complete exon ordering and complementary strand. Every old design, input, mapping, replay and response byte is bound by hash. The eight HTTP200 region responses for four regions are reused through their existing immutable receipts. The original v1 transport helper would hash a missing cache file on resuming a recorded transport failure. Orphaned or changed caches are rejected. Any newly failed request remains missing; no successful-parent substitution or region extension is allowed.

## Bounded immutable public requests

The complete deduplicated region roster is frozen from every original author candidate before any new query. Convert source start1/end1 to UCSC `[start1-1,end1)`. Supported chromosomes are original mouse 1–19/X/Y/MT, with the declared UCSC chrM spelling for source MT. Sort regions lexically by chromosome, start and end. Each must be at most **500,000 bases**, with at most **100,000,000 eligible reference bases total**, including reused pilot intervals. If that total is reached, later fixed regions remain capped; the roster is never reordered using outcomes or mapping convenience. Each eligible region gets exactly one knownGene and one reference-DNA request, unless its exact old pilot response is reused. No all-genome download is attempted.

The response cap is **4,000,000 bytes**. A declared oversized response is not read; an unknown-size response may read a single sentinel octet beyond the cap solely to detect overflow. No more than 4MB of an overflow prefix is retained, with its own SHA, and no truncated response is treated as reference data. Every request is spaced by 1.05 seconds; timeout is 45 seconds; no automatic retry or extra-query fallback. Redirects outside the exact official API host/endpoints are refused before following. URL, final URL, HTTP status, UTC time, size, actual SHA and public-use source terms are recorded immutably for each body/receipt. Failures are metadata missingness, never negative biological evidence.

The [UCSC API documentation](https://genome.ucsc.edu/goldenPath/help/api.html) specifies sequence/track endpoints and recommends no more than one hit per second. [UCSC licensing](https://genome.ucsc.edu/license/) permits public website/API and table-data use while retaining source-database requirements; attribution is required where applicable. Only public reference sequence/annotation is requested, with no account, key, payment or installation. The current official documents were checked during preparation; their URLs and the byte-pinned previous catalog/schema identify the source. Future phyloP/phastCons or aligned-base extraction would require a new explicit track/release/species-set and missingness design; it is not authorized by this coordinate generation.
