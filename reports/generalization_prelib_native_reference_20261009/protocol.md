# Fixed native-reference identity expansion
Five literal WT native-source peak coordinates are compared with hg19 genomic windows expanded300bases on each side. This is a fixed assembly comparison, not a claim that coordinate names uniquely certify author assembly. Each window's refGene annotations are separately retrieved. Check exact whole140nt sequence on declared strand; report all matches, and only explicitly covering exons. Genomic/exon matches do not certify mature full reporter RNA or engineered backgrounds. Preserve original nominal source symbols and any annotation aliases.

NORAD uses explicit historical NR_027451.1 and current NR_027451.2 GenBank requests. No unversioned/latest substitution. Report both versions' lengths and all forward140nt WT hits. Existing IRF2BP1hg19/RefSeq certificate is preserved separately. No outcome, read, new trained model, author code, paid source or account is requested.

Thirteen requests fixed before download;128KiB each,10s timeout,150s acquisition total, one attempt without retries or dynamic alternative references. New metadata reader fresh1.3GiB,768MiB child cap,180s wall cap; original feature/model3GiB floors unchanged. Sources: [UCSC API](https://genome.ucsc.edu/goldenPath/help/api.html), [NCBI NORAD](https://www.ncbi.nlm.nih.gov/gene/647979).

A fixed hg38 sequence query at the same SMARCA2 numeric window is included because its official GRCh37/38 gene bounds coincide. Positive matches in both assemblies do not uniquely identify the source assembly. No hg38 gene annotation query or dynamic alternative is added.
