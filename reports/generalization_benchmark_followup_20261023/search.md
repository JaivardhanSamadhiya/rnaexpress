# Bounded metadata follow-up: a new ER-reporter lead

On 23 October, a literature search located the primary bioRxiv abstract for
[Haimovich and colleagues, SECReTE reporter screen](https://www.biorxiv.org/content/10.64898/2026.10.12.758471v1),
DOI 10.64898/2026.10.12.758471. The page says posted 13 October 2026. It describes
approximately 50,000 synthetic variants in two reporter constructs, tested in
Chinese hamster ovary cells for ER/cytoplasm partitioning and secretion.
The preprint page is publicly accessible and states CC-BY-NC-ND 4.0; this does
not establish the availability or license of an underlying numerical dataset.

This is a potentially relevant reporter-transfer resource, not an admitted
small-edit or unseen-gene benchmark. Exact parent/edit relationships, edit sizes,
independent sequence families, replicate files and a free public data accession
remain unverified. Two reporter backbones do not establish broad gene or cell
generalization. The abstract's qualitative motif conclusions are exposed, so
the study cannot be described as completely literature-blinded.

The full-page fetch returned HTTP 403. Three bounded searches for the exact
DOI/data availability, a GEO entry and a GitHub repository did not identify an
associated usable accession. That is an unresolved search result, not evidence
that data are absent. No supplement, sequence table, outcome file or dataset was
downloaded, admitted or scored. No author was contacted. This lead does not
change any existing gate, holdout or claim, and does not delay the admitted-data
implementation work.

Searches also returned previously known Astrocyte, SRLE, Mikl, Faraway and
N-zip literature. No protected outcome payload was opened. The search-result
snippets are literature exposure, not a new independent validation dataset.
