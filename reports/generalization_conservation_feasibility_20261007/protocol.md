# Outcome-blind conservation coordinate feasibility

Declared 7 October 2026. This checks whether the original admitted parent inserts can be assigned reference sites before considering evolutionary annotations. It reads only explicit identity, gene, sequence, author design-offset and coordinate metadata. No localization/stability/replicate/protected outcomes, feature matrices, models, conservation values, fitting or evaluation gate are accessed. All current experiments and verdicts remain intact.

The exact six-column NEXT sequence inventory and its committed prefit hash anchor the 26,258 admitted allele IDs. The canonical core is read only for intervention_id, gene_transcript, parent_id, mutant_id. Mikl's original TableS2 is read only for gene name, position in 3UTR, subset and full library sequence; its preserved lineage is read only for source_row, mutant_id, parent/mutant sequence, gene_name and organism. Astrocyte's already frozen metadata is read only for element, parent_id, gene, parent/mutant sequence and genomic_or_utr_position. These author offsets are not assumed to be genomic coordinates. Moffatt's engineered parent inserts remain exact reported sequences, without invented chromosome/assembly metadata. SRLE sixmers and certified local vector/HBB arms are synthetic reporter context and receive no native genomic mapping.

The existing author RNAloc_MPRA LibraryDesign **code cells only** specify BioMart mouse GRCm38.p6. Its mouse_3utrs FASTA has Ensembl gene/transcript IDs, gene symbol, chromosome and gene start/end headers. Stream this sequence-only reference and enumerate every exact parent occurrence for the matching case-folded gene name. A unique transcript occurrence is preliminary metadata coverage, not proof of a unique genomic site, strand, transcript release or complete mature reporter. Preserve multiple and absent occurrences. The author-code isoform filtering and removal of the distal polyadenylation region means a nominal author position alone cannot safely determine the native genome base.

Freeze pilot IDs before any remote mapping: for each non-SRLE study select its sorted gene names at first/middle/last positions, removing repeated indexes; select the first/last sorted parent IDs of each gene, removing repeats. Keep all admitted candidate allele IDs for those parents. Selection uses no effect, score, outcome availability ranking or conservation. All failed/ambiguous parents remain in the receipt; no substitutions of easier genes.

Only official public UCSC mm10/GRCm38 APIs supply the small pilot reference. Catalog/schema metadata identifies **knownGene / GENCODE VM23**; `ensGene` is not present in the inspected catalog, so it is not guessed. Convert author Ensembl gene start1/end1 inclusive to UCSC [start1-1,end1). Query knownGene records and genomic DNA only in those fixed regions. Each region is capped at 500,000 bases; total is capped at 2,000,000; each response at 4,000,000 bytes. Preserve cap failures and request errors. Do not extend intervals, use approximate matches, alias guesses, current mm39 sequence, BLAT, liftover, all-genome downloads or nonprimary hosts. At most one request per second; no accounts/keys/installations/costs.

Require a version-stripped stable transcript ID from the author's exact UTR candidate list to match the returned annotation. Reconstruct the transcript's coding 3UTR using all original exons and strand: plus-strand exon portions after cdsEnd, minus-strand portions before cdsStart in reverse genomic order with complementary bases. Noncoding transcripts lack a certified coding 3UTR and do not pass this rule. Require the entire parent insert to match exactly. Retain every match, collapse only identical chromosome/strand/complete genomic-position vectors across transcript records; zero and multiple distinct vectors stay unmapped/ambiguous. A unique vector establishes a reference coordinate among the anchored candidates, **not genome-wide uniqueness or proof of the exact biological isoform used**. Each edited nucleotide and forward-genome reference/alternate base must replay from this vector. Candidate-specific engineered sequence, splicing, barcodes and whole-reporter processing remain uncaptured.

Write a design manifest binding source, tests, this protocol, metadata, complete allele roster and input bytes. Root commits it before remote mapping. Cache every response with immutable URL/status/UTC/byte/SHA receipt. Recheck all frozen source/input bytes before and after the pilot. Missing data are never assigned zero conservation. This generation does not download or score phyloP/phastCons/multiple alignments. Its deliverable is coordinate coverage and the next certificate required before any label-blind evolutionary feature extraction or separately frozen prediction experiment.

Official sources: [UCSC API](https://genome.ucsc.edu/goldenPath/help/api.html) documents the reference/track endpoints, coordinate parameters and light-query recommendation. [UCSC licensing](https://genome.ucsc.edu/license/) permits public API/data use while retaining source-specific restrictions. [Ensembl access](https://static.ensembl.org/info/data/index.html) states one-based starts and freely available project data; its [disclaimer](https://sep2025.archive.ensembl.org/info/about/legal/disclaimer.html) preserves third-party restrictions. [NCBI molecular-data policy](https://www.ncbi.nlm.nih.gov/home/about/policies/) imposes no NCBI reuse restriction but does not transfer third-party rights. Public/free access is verified, with attribution; no assumption that every external resource has the same license. The official [mm10 conservation track](https://www.genome.ucsc.edu/cgi-bin/hgTrackUi?c=chr17&db=mm10&g=cons60way) supplies future phyloP/phastCons documentation only. Conservation measures evolutionary constraint and does not determine localization direction or cell-specific binding state.

Historical bounded source/config/report search found no implemented phyloP/phastCons/site-MSA feature experiment. Mechanism-v2 HCOP/HGNC gene-family grouping and FinalShot MGI RBP-channel orthology are existing ideas for gene-family leakage/proxy mapping, distinct from exact edited-base conservation. This is a coordinate feasibility refinement of established biology, not a novel mechanism or proof that evolutionary information will generalize.
