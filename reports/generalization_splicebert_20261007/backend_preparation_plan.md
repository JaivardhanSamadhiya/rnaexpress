# SpliceBERT CPU backend preparation

Use the author-verified local `SpliceBERT.1024nt` checkpoint, with no new model variant or project-allele inference. The repository has an established Torch BERT wrapper → `ov.convert_model` path in `src/analysis/audit_v4_openvino_backend.py`; it has no established checkpoint-to-native-OpenVINO BERT-ops builder. Reimplementing tensor names and BERT operations with a static parser would add graph-correctness risk. The new disjoint probe copies the conversion pattern while avoiding the old script's historical benchmark inputs. [OpenVINO's official conversion documentation](https://docs.openvino.ai/2026/openvino-workflow/model-preparation/convert-model-pytorch.html) recommends example inputs and identifies ONNX as a fallback with extra overhead.

The official PyTorch index pins CPU2.6.0, CPython3.12, Windows x64, SHA256 `4027d982eb2781c93825ab9527f17fbbb12dbabf422298e4b954be60016f87d8`. Its published download-r2 link rejects HEAD and GET. A normal GET on the same path at PyTorch's official `download.pytorch.org` mirror succeeded:206,493,444 bytes and exactly the published checksum. Both the initial incident and successful receipt are preserved. No credentials, special access headers or authorization bypass was used. This pin is a compatibility choice, not a claim to the newest runtime. [Official previous-version instructions](https://pytorch.org/get-started/previous-versions/) document the CPU index.

Wheel files are data-only extracted into `artifacts/generalization_splicebert_20261007/cpu_runtime`, with original archive SHA and exact extracted-file parity. Missing fixed dependencies SymPy1.13.1, mpmath1.3.0, NetworkX3.4.2, Jinja2 3.1.6 and MarkupSafe3.0.3 are separately downloaded from official public PyPI metadata, checksum-verified and extracted into `dependency_runtime`. Licenses and dependency metadata are retained. No system package installation or `.pth` startup hook is performed. Existing Transformers4.40.2, shared OpenVINO2026.3.1/tokenizers and other bundled/project libraries are reused with source-hash snapshots; original wheel parity is claimed only where actually available.

Root commits the new probe, final standard-library tests/receipt, this plan and `backend_preparation_manifest.json` before explicitly passing `--root-start`. The manifest pins source, provenance/configuration, metadata, wheel hashes and extracted/reused-runtime receipts; startup independently checks actual runtime source bytes. Immediately before runtime import, require at least3GiB currently free RAM and5GiB free workspace disk. Run one model/conversion process, two CPU numerical threads and no replicas. The guard currently prevents work when the memory floor is unmet. Package import, deserialization, conversion and synthetic model inference have not been tested yet and may expose compatibility limits.

Construct the stock local `BertModel` from its JSON, with no remote code. Explicitly call `torch.load(weights_only=True,map_location='cpu')`, with memory mapping only for ZIP checkpoints; never allow unsafe fallback or add pickle globals. Load every encoder parameter strictly. Omit only the unused MLM head; optional legacy position/token-type buffers are accepted only after exact comparison to their deterministic expected values. No finetuning, model search or checkpoint-selected outcomes enter this procedure.

Sixteen predetermined synthetic alleles cover46/150/190/260nt, two one-base edit pairs per length. The46nt examples use the certified SRLE20+6+20 arms and synthetic interior, preserving the below64nt author-warning limitation. Verify manual single-base IDs against the author-local slow tokenizer, convert FP32 with dynamic batch/sequence dimensions, and compare native Torch and one compiled OpenVINO CPU model. Fixed numeric checks per batch are maximum hidden-state difference≤.001, mean difference≤.0001 and minimum token cosine≥.999999. Save IR and a PASS receipt only as backend admission; no localization outcome is loaded. A failed candidate IR is preserved and not certified for production.

The guarded command after root's start signal and recovered RAM is `python -u -m src.generalization_splicebert_20261007.backend_probe --root-start`, with PYTHONDONTWRITEBYTECODE=1 and OPENBLAS_NUM_THREADS=OMP_NUM_THREADS=2. No full-core inference, feature assembly or supervised fitting is exposed by this module. Full feature production still needs a separate committed protocol, producer guards, observed throughput/memory feasibility and root's explicit start signal.
