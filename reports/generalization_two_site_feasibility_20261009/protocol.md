# WT-only two-site opportunity audit

This is an outcome-blind metadata feasibility follow-up on an exposed binding resource, not a new binding mechanism, measured cooperativity, independent localization validation or gate revision. Becker et al.2019 experimentally demonstrated PUM2 cooperativity mediated by RNA folding without direct protein cooperativity. Their predictions were weaker in practice than naive folding predictions. Current fixed PUM mathematics is a one-bound-protein ensemble; the frozen joint-accessibility route weights individual complete contiguous motif intervals. Neither computes the simultaneous opening of two disjoint sites.

Before any biological sequence is inspected by this generation, freeze own source/protocol/synthetic receipt and exact admitted metadata/parameter input hashes. No workbook, IP/input, counts, repression, localization, mutant relation table, models, numerical feature arrays or protected sources are opened. Do not import scientific runtimes or download anything. Original frozen bytes, gates and RAM floors remain unchanged.

Use exactly the eight non-mPRE author native WT template rows already certified by the v2 literal ancestry audit (seven nominal gene groups; NORAD's two fragments remain one lineage). Keep every WT, including zero/one-site templates. Source symbols are nominal; no new genomic identity or full mature reporter reconstruction is implied. Verify parent IDs, Excel rows and existing parental sequence SHA; require the v2 design birth receipt and ancestry parent receipt hashes. The TableS4 JSON file contains other metadata sequences internally. A selective standard-library lexical reader skips nonselected row values without decoding their sequence/ID strings; only the fixed eight WT row dictionaries are semantically decoded. Entire bounded bytes are read for SHA/parsing. No mPRE or mutant sequence scan.

Fix forward canonical eight-base PRE UGUA[N]AUA, N in A/C/G/U, before coverage. Require an available ninth consecutive base so the released nine-contact parameter model can define the site's energy. DNA T becomes U; no reverse complement, padding or flanks. Canonical terminal eight-base matches lacking the ninth base are explicitly recorded as ineligible. Fixed recognition positions mean only the seven specified motif positions, not evolutionary conservation or unchanged sites between alleles. No energy cutoff or spacing grid is used.

Enumerate every qualifying site and every pair with disjoint computational nine-base contact intervals. Coordinates are zero-based half-open; intervening gap is right_start-(left_start+9). This computational footprint is not an experimentally certified steric exclusion boundary. Report all pairs, core gaps, contact-window gaps and zero-support WT backgrounds. Calculate fixed coupled-consecutive energy from the already pinned CSV operator (25C, entire position9 conditional on position8A); canonical cores have position8A and therefore neither published c1 nor c2 activates. No flip states are scanned. This narrow canonical-site audit cannot establish absence of noncanonical/gapped binding or binding outside140nt inserts.

Select at most ONE prospective pair per WT: minimum sum of the fixed consecutive energies, then lexical left/right start. Selection uses sequence/parameters only, never measured affinity or labels. Keep all qualifying pairs descriptively. The sparse roster is for a possible later synthetic/WT folding feasibility, not a selection of favorable target outcomes or an admitted model feature.

A future paired-opening calculation would constrain both nine-base windows simultaneously unpaired while leaving intervening bases free; replacing this event with opening the full intervening span is incorrect. Compare P(A and B open) against P(A open)P(B open) and report availability/numerical error. The ratio is structural dependence, not protein occupancy or interaction free energy by itself. Concentration-dependent multi-PUM occupancy would require a separate reviewed activity/calibration and excluded-state model. No such folding is authorized here. No minimum coverage or GO gate is invented after counts: limited support is a reason to defer breadth claims.
