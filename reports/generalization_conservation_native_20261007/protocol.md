## Second freeze and value stage

The root must review/commit this second exact manifest before starting values. Query syntax is fixed as `genome=mm10;track=phyloP60wayAll,phastCons60way;chrom=CHR;start=START;end=END;maxItemsOutput=10000`. No reference windows are enlarged and no annotation request is chosen by outcome or response score.

Match that track's exact logical type and chromosome-specific physical timestamp pair from the second freeze. Require exact assembly/chromosome/interval, finite numeric values, phastCons within [0,1], unique nested fields, nonoverlapping in-bounds half-open row intervals and an exact total row count below the output cap. Reject unknown root schema, changed table/type, ambiguous duplicate metadata, boolean scores, nonfinite constants, out-of-bounds intervals, HTTP 206, any `maxItemsLimit`, error payload or missing source group. Negative phyloP values are valid. Empty source arrays and absent bases mean missing, never zero. If the live response differs from the released-source contract, preserve failure and do not adapt this generation.

The representation is explicitly the UCSC browser/API wig representation, not certified original full-precision download values. Exact track/schema/storage type/source timestamps and actual response bytes are recorded. No alignment or ancestral-base interpretation is available from scalar scores.

## Public transport, bounds and preservation

The public API/data require no account or purchase; see [UCSC licensing](https://genome.ucsc.edu/license/). Public source inspection retains the repository LICENSE: default MIT coverage has noncommercial exceptions including the inspected `hubApi` sources. No source was compiled or installed. [API conditions](https://genome.ucsc.edu/goldenPath/help/api.html) recommend about one request per second. Sleep 1.05 seconds before every new request; timeout 45 seconds; no automatic retry or changed-URL redirect. A redirect must preserve the exact HTTPS URL and trusted host. Only fixed roster URLs are allowed.

Each response body is capped at 4,000,000 bytes; total acquired bytes across both stages are capped at 100,000,000. Unknown response length is read to at most a cap-plus-one sentinel, included in the total budget; preserve a bounded overflow prefix and its hash. A declared oversize body is declined without reading it. Failed HTTP/transport requests keep immutable receipts; cached failures are not retried or mistaken for body files. Every first-created receipt has a content-SHA sidecar; changed receipt/body bytes and orphaned files fail closed. No existing response, receipt or output is overwritten. Budget exhaustion stops without a false completion receipt. Value spacing alone is at least 52.55 minutes, excluding network/IO/parsing; 42 schema waits add 44.1 seconds.
