# Native constraint and alternate-consensus feasibility: preparation only

This is a separate narrow proposal for external evolutionary information after complete coordinate certification. It authorizes no annotation-value or alignment-base query, no production feature, no phenotype/model read and no fit. The ongoing coordinate generation and every earlier freeze stay unchanged. Root review and a new committed extraction design are required before any proposed values are fetched.

## Admission is exact certified edited sites only

The required input is the completed `generalization_conservation_mapping_20261007` mapping **and independent replay PASS**, with their design/completion/body/receipt hashes. Until those exist, this proposal has no admitted site roster. Keep all 26,258 original intervention IDs and complete parent menus; an unassigned/ambiguous/capped/partially resolved parent supplies no coordinate. Moffatt/Sparc lacking exact source anchors and synthetic SRLE are not rescued by approximate matches, gene aliases, a human HBB reference, guessed reporter sequences or another assembly. A uniquely certified site remains uniqueness among fixed author candidates, not genome-wide uniqueness or the actual expressed isoform.

Freeze the union of every fully certified edited position `(mm10 chromosome, forward-genome position0)` and its certified reference/alternate bases, preserving row/edit mappings. Merge only immediately adjacent admitted positions into half-open request intervals; never bridge introns or unassigned gaps, or extend to favorable regions. Deduplicate shared cell/allele positions for retrieval, then restore the complete original row/menu roster. Record request/byte/interval feasibility before values. If bounded extraction is not practical, defer; never select genes or a cutoff from conservation values or localization outcomes.

## Distinguish native-site scores from allele evidence

The cached official mm10 catalog has `phyloP60wayAll` (wig), `phastCons60way` (wig) and `multiz60way` (wigMaf). The [official conservation description](https://genome.ucsc.edu/cgi-bin/hgTrackUi?db=mm10&g=cons60way) identifies the all-60-vertebrate alignment, including reference mouse. PhyloP evaluates sitewise evolutionary constraint/acceleration; phastCons estimates conserved-element membership using neighboring alignment context. Missing/gapped bases need explicit missingness.

**Neither native score is a measured mutant-allele score.** Querying the same position for parent and mutant returns the same annotation. Calling the resulting difference a mutation-specific change in phyloP/phastCons is invalid. Different edited-site locations can have different constraint, but candidate alternates at the same location cannot be distinguished by those native values alone. Constraint does not supply the sign of localization, cell-specific transport, occupancy or causal fitness.

Proposed fixed native block for a later extraction review: for each of the two all-species tracks, observed edited-site mean and maximum; plus each track's observed-site fraction and a coordinate-availability flag. No threshold-selected high-conservation subset or clade search. Missing numerical placeholders are computational zeros accompanied by masks, never a claim of zero constraint. A paired coverage-only control uses those fractions/availability and the same original rows. Incremental comparison against that control is needed before attributing any gain to constraint rather than mapping/annotation support. This proposal does not decide a predictive learner or rescue an old generalization gate.

## Allele-aware aligned-base evidence is a different, currently unadmitted source

Alternate-consensus evidence requires the actual aligned bases at a certified site, rather than a conservation scalar. A tentative exact rule, fixed before any aligned column is seen: use the all-60-way source, exclude reference mouse, keep one unambiguous A/C/G/T observation per declared nonmouse species at the certified mouse position, and treat gaps/N/absent/duplicate conflicting rows as missing. Transform aligned columns to forward mouse orientation and verify their mouse base against the coordinate certificate; transcript-minus strand does not reverse an already forward-genome allele again.

For reference/alternate counts `n_ref,n_alt` in that one column, a simple prespecified surrogate is `log((n_alt+0.5)/(n_ref+0.5))`; sum and mean these per-edit contrasts for the candidate. The 0.5 pseudocount is fixed rather than fitted. Record nonmouse support and missing fractions separately. It is an empirical species-count contrast, not ancestral-state inference, phylogenetically independent evidence, a joint multibase likelihood or localization/fitness probability. Closely related species are correlated; low-coverage assemblies and alignment/paralog artifacts can bias counts. No support threshold, species subset, consensus base or pseudocount may be chosen after coverage or outcomes. A source-only learned relationship to localization would still need a separate frozen experiment and appropriate information controls.

This alignment route is **not production-ready**. The cached catalog marks `multiz60way` as `wigMaf`, while the [official REST supported types](https://genome.ucsc.edu/goldenPath/help/api.html) list `bigMaf` and wiggle, but do not document wigMaf retrieval. Do not equate formats or assume the existing track JSON endpoint returns aligned nucleotide columns. A documented bounded regional MAF/Table Browser or genuinely indexed official source must first be demonstrated under a new read-only source-admission plan. Whole-chromosome/genome alignment downloads, undocumented endpoint guessing, assembly substitution and silent alternative-source adoption are forbidden. Native score availability cannot certify alternate-consensus availability.

2. Separate metadata admission for exact all-species score tracks: schema, current source/release/dataTime, types, public terms and a fixed request budget. Query payloads must be regional/bounded, nontruncated and birth-SHA bound; one request per second, no retry or source substitution. 3. If native extraction is authorized, bind every site value/missing state to an unchanged reference site and track receipt. Independently replay site joins, both transcript strands, numerical ranges and masks; preserve all original rows. No biological direction is assigned by the annotation.
4. For alternate-consensus only, obtain independent bounded MAF-source and aligned-mouse base/strand certificates, exact species/assembly roster and unambiguous column reconstruction. Otherwise defer it explicitly.
5. Only after value extraction/missingness audit and a separate prefit freeze, compare coverage-only, native-constraint and allele-aware blocks against the same source-only controls/purges on the same original cohort. Conservation annotation is established prior biology, and these repeatedly exposed sources do not become independent confirmation. No universal or STS-success claim follows from metadata feasibility.

The [UCSC licensing page](https://genome.ucsc.edu/license/) permits public API/table-data use with source-specific conditions and attribution. This proposal uses free public metadata and existing caches; no account, purchase, installation, cloud job or scheduled task. No annotation values or alignment columns have been queried during preparation.

## Precision and mutation-direction limits

The [official UCSC downloads FAQ](https://www.genome.ucsc.edu/FAQ/FAQdownloads.html) warns that wiggle database/browser and Table Browser conservation values can be lossy relative to original score downloads. Before any extraction, pin the exact track/storage schema, endpoint representation and available precision; call admitted API values that representation, never silently certify original full-precision PHAST scores. No whole-genome download is authorized to repair this gap. The same FAQ states programmatic browser CGI queries need an API key, whereas its REST API does not; bounded Table Browser MAF export therefore also needs an authorized access method rather than an account or undocumented scraping workaround.

The proposed native mean/max block is an edited-site covariate, invariant under swapping reference and alternate at the same coordinate. It is not an antisymmetric mutation-effect feature, and native parent-minus-mutant annotation remains zero. Later inference must compare against fixed same-position raw edit features and coverage controls; any allele-aware interaction must be separately prespecified before fitting. A positive result could show helpful native-site context, not that conservation itself supplies the preferred alternate or directional localization effect.

## Completed coordinate and source-metadata feasibility

The full mapping and direct independent replay have now passed without scores, outcomes or models. The metadata-only site inventory binds their exact birth hashes and retains every original row. It certifies 15,132 distinct forward-genome edited sites and 25,593 distinct site/reference/alternate triples, from 15,769 rows and 4,465 complete menus. Across the original cohort, 174 of 187 Mikl genes and both Astro biological components have some certified rows; missing coverage persists across every Moffatt and synthetic SRLE row. This supports a narrower compatible-cell feasibility assessment while limiting any whole-assay transfer interpretation. It supplies no localization performance evidence.

Adjacent-only merging produces 3,003 intervals covering exactly those 15,132 sites, maximum interval 320 bases. Two scalar tracks would require 6,006 requests; the existing 1.05-second spacing alone implies at least 6,306.3 seconds (105.105 minutes), excluding latency. This is only a proposed immutable query roster, not extraction authorization. A separate review must fix total response bytes, per-response cap, rate, no-retry receipts, track admission and missingness handling before values are requested.

Five official Ensembl GRCh37 metadata requests were observed under a 4 MiB response cap, 1.05-second request spacing and no retry, with immutable local bodies/receipts. `info/species` reports human GRCh37 only, data release 116; the mouse core assembly metadata request returned HTTP400 without an admitted body. `info/compara/species_sets/LASTZ_NET` nevertheless lists 22 species sets containing `mus_musculus`, among 406 sets. This is not evidence that the mouse Compara reference is GRCm38: the response gives species names/methods, not assembly IDs or mouse reference-base parity. Hence neither absence of mouse from the core list nor presence inside Compara proves compatible mouse coordinate access.

The [official bounded alignment method](https://grch37.rest.ensembl.org/documentation/info/genomic_alignment_region) documents aligned regional blocks and LASTZ methods. It is a possible future source, requiring explicit exact mouse assembly, comparative release, method/species roster and forward reference parity certificates before any alignment-base query; pairwise LASTZ columns would not silently become the all-60-way species-count feature defined above. [Ensembl data access](https://www.ensembl.org/info/data/index.html) describes its public data as freely available, with one-based starts. No aligned columns, conservation values or project outcomes were queried. No source substitution, liftover, favorable species subset or annotation threshold was selected.
