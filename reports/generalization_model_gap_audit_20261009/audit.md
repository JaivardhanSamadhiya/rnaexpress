The broad proposals are already represented in this project: absolute allele predictors evaluated as mutant minus parent, shared predictors with context-specific adjustments, and jointly shrunk group rankers. A new experiment could reassess narrower differences in objective, grouping and split protections. It cannot honestly introduce either broad modeling idea as missing or novel.

This audit read source and admitted narrative reports only. ## Mathematical duplicates and real distinctions

For a linear potential `F(s,c)=beta_c.T phi(s)`, its paired effect is exactly `beta_c.T[phi(mutant)-phi(parent)]`. Renaming a linear absolute-feature delta predictor as a paired potential adds no function span. Subtracting a parent constant also cannot alter candidate order inside a fixed-parent menu. A difference-trained model can change fitted coefficients because its loss differs; that is an objective comparison, not automatically a new representation.

The V4 comparator assigns each parent zero and the lowest-utility mutant zero, regardless of whether that mutant's measured effect was zero. It is internally a declared normalized-choice comparator, but its pseudo-absolute training targets do not establish an absolute localization scale. The claim in its docstring that this is the only identifiable absolute-forward construction is too strong: a difference-only objective can identify relative potentials up to graph/model-dependent gauges without forcing every parent state to zero. No old result is changed by this observation.

FinalShot's local parent mass varies with edit location; gain, loss and maximum-absolute-delta features depend on both alleles. Its intervention score therefore need not satisfy potential reversal or path-additivity. One cannot equate that score with `F(mutant,c)-F(parent,c)` simply because the feature pipeline contains allele differences.

For an M2 feature block with cell expression constants `a` and `b`, the effective slopes are `w+a*v` and `w+b*v`. When `a != b`, this has the unregularized function class of two independent cell slopes. Sparse/group penalties couple the fitted coefficients, and ineligible groups or equal constants remain shared. This audit did not read expression values, so it does not assert that every actual block has two distinct constants.

Adding only a cell intercept changes neither within-cell pair differences nor ranking. Positive affine or positive two-knot heads preserve ordering within a head; in FinalShot, any cell-dependent reorderability comes from the input interactions and fitted latent coefficients, not the monotone head alone.

## Bounded next freeze recommendation

Do not construct a broad new search. The smaller possible reassessment is a **known-cell, unseen-gene** comparison on one fixed admitted feature block and unchanged complete menus: pooled coefficients, independent cell coefficients, and jointly shrunk cell deviations. Use one common pair roster, training-only pair-RMS scaler, loss, biological weighting and original global gene/component/exact-allele purge. Both cells are represented in training outside held genes; this is not unseen-cell or unseen-study transfer.

For two cells, use an identifiable contrast `score=x.T beta + cell_sign*x.T delta`, cell_sign ±1, with a fixed deviation penalty multiplier such as the old10. Include pooled `delta=0` and matched independent-cell controls with explicitly calibrated penalty normalization. At multiplier1, the sum/difference parameterization has a known equivalent independent-head objective; synthetic tests must verify that equivalence. Select any small common L2 grid using training genes only, combining held-inner predictions before equal-gene aggregation. Freeze all cell/model identities, canonical tie rules, primary/increment gates and correlated component resampling before new outputs. This is a controlled re-evaluation of an existing modeling idea, using exposed development data.

A separate paired-potential generation is justified only if it tests a concrete distinction: for example, a fixed nonlinear allele function trained through a difference-only effect objective rather than pseudo-absolute anchors. It needs matched capacity/loss controls and an edit-independent allele encoding. Local pools chosen using the parent–mutant change positions are pair representations, not a standalone `F(sequence,cell)` unless that extra conditioning is declared. Require synthetic self-zero, reversal, path-additivity, parent-cancellation, gauge, checkpoint and canonical-replay tests. Do not introduce that objective and cell conditioning simultaneously if the intent is to isolate which difference helped.

No experiment, input admission, gate revision or execution is authorized by this recommendation. Preserve every existing frozen file and result, protected outcomes, resource policy, runtime and failed verdict. Public-data novelty and biological confirmation remain separate questions.
