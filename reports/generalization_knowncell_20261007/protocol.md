# Prospective represented-cell held-gene evaluation

This is a new evaluation of already fitted crosscell predictors. It asks whether candidate-edit ranking generalizes to held genes **conditional on a represented cell**. It is an exposed same-data development follow-up, not independent biological confirmation, unseen-cell/study generalization, a rescue of earlier gates, or the first demonstration of gene-held-out RNA localization prediction. The protocol is declared before opening new target predictions or old model performance.

## Fixed population and masks

Use all 13,781 admitted Mikl rows, all 187 original biological components and inherited gene folds 0/1/2. CAD has 6,889 rows and Neuro-2a 6,892. Keep every original candidate menu, original intervention IDs, lexical exact-score tie rule, assay effect orientation and finite informative spans. No target-intersection trimming or outcome filtering is allowed. No other assay, reserved outcome or replicate table is admitted.

For each of seven original tracks and three folds, reuse the original CAD_to_N2A source model to score **CAD** in the held fold; reuse N2A_to_CAD to score **Neuro-2a** in the held fold. These are 42 reused outer predictors and zero fits. Preserve the exact original source mask, source-only two-fold combined OOF selection, penalty order .005/.05/.5, 1e-12 configuration tie tolerance, pair-RMS scaling and capped historical pairs. Never select from any same-cell target or crossed-cell outcome.

The old purge was constructed against the opposite-cell target. Reuse therefore requires a separate outcome-free proof that its exact training mask has no original parent/mutant allele, normalized gene or biological component overlap with the new same-cell target. Reject an unsafe mask; a union-purged refit would require another separately frozen experiment. Require target menus complete and all cell/fold rows covered exactly once. Current metadata proof shows zero overlaps and partial menus in all six masks; this is not a general guarantee for other cohorts.

## Fixed comparisons and scope of a pass

Tracks and feature widths remain simple102, base246, raw251, structure262, lookup502, bert502, combined518. Only structure, bert and combined can qualify a conditional development claim. Raw and lookup remain information/capacity controls. No new feature or model setting is introduced.

Keep the previous narrow numerical gate, now explicitly labelled represented-cell scope: macro normalized extrema regret at most .48; each cell below uniform .5. Against **both base and simple**, require macro improvement at least .01, improvement at least .005 in each cell, positive lower paired 95% interval, positive improvement after removing the best inherited gene fold, wrong-direction harm no more than .02 macro and .05 in either cell. Use 5,000 shared global-component exponential bootstrap draws with seed 20261007. Weight directions/menus equally within component, then components/cells equally; after fold removal recompute component weights rather than average unequal folds.

Information controls require mean improvement at least .01 and positive improvement after best-fold removal: structure versus raw; bert versus lookup; combined versus structure and bert separately. No single informed track is chosen retrospectively for a new confirmatory test. A pass is CONDITIONAL_CELL_DEVELOPMENT_GO and leaves every previous whole-assay and unseen-cell gate unchanged. Multiple exposed comparisons and shared data limit the evidential claim; the gate is a development criterion, not familywise significance or proof of novel biology.

## Prespecified descriptive same-state/crossed-state contrast

For every track and both source cells, compare the new same-cell regret with the original opposite-cell regret from **the identical source checkpoint and configuration**. Pair only exact complete parent+candidate sequence menus in the same original gene/fold, without taking an allele intersection. Keep original intervention-ID tie order in each cell and report lexical allele-order mismatches; do not relabel ties to improve either arm. Metadata identifies 2,408 paired menus, 13,760 paired rows and all 187 genes; nine unmatched contexts/21 rows are excluded only from this contrast, never the main evaluation. There are no exact Moffatt GFP/Firefly menus in the preceding metadata audit; Moffatt is outside this evaluation.

Report crossed-state minus same-state regret, directions/menus equally within gene, then all genes/source cells equally, with the same shared-component bootstrap as a descriptive interval. Report all seven tracks and three prespecified descriptive strata: all exact menus; lexical allele order equal (760 menus/3,308 rows/162 genes); lexical allele order different (1,648 menus/10,452 rows/169 genes). Strata are metadata-defined before any performance inspection and select no track or claim. The main gate retains every row and all 187 genes. Different intervention-ID tie orders can select different alleles under identical tied utilities; full validation matrix shapes can also change floating reduction at exact ties. Preserve original canonical scores and disclose these limitations. The contrast selects no model, changes no gate and is not a causal effect of cell state, Bayes/noise ceiling or independent confirmation. Barcodes, assay noise and other context differences remain possible explanations.

## Integrity and start conditions

A separate **canonical paired-allele descriptive contrast** is also fixed prospectively for every track/source checkpoint/fold, all 2,408 exact menus and all 187 genes. Certify that each paired parent+mutant allele's complete feature bytes are exactly equal across cells after the declared float64 model input conversion. Feature-byte inequality blocks this diagnostic; no tolerance, cell normalization or removal of failing menus is allowed. Assemble one ordered complete paired-menu matrix (metadata menu order, lexical mutant sequence within each menu), and call the same frozen predictor **once** in that common shape. At exact score ties choose the lexical mutant sequence shared by both contexts. Evaluate that identical chosen allele against both original effect menus, retain both original intervention IDs, and report the same equal-menu/gene/cell regret contrast/descriptive interval. All seven tracks are reported. This removes intervention-ID tie order and differing validation-shape reductions from this specific diagnostic; it changes no primary selection, original scores, ID-based decision policy, gate or earlier all/equal-order/different-order contrast. It cannot establish a causal cell-state effect, independent confirmation or a biological noise floor. No tie band or favorable outcome-based ordering is introduced.

Preparation reads explicitly selected metadata columns only. No models, feature arrays or effect columns are needed for mask/menu certification. Synthetic tests use invented arrays/outcomes and never invoke an estimator. The evaluation freeze is written only after the original crosscell seven tracks and independent source verifier complete. It pins the original prefit, current checkpoint/result bytes, selected original features, new code/protocol/test/metadata receipts and dependency sources. Root commits this manifest before new scoring. Post-fit hashes preserve observed checkpoint bytes; they do not retroactively certify checkpoint creation time.

Future scoring reads only the already admitted Mikl mean-effect rows with the original default parser, no replicate reader. Verify original training IDs/parsed labels/config/cell/components/folds against old checkpoint metadata; matrices bind through the immutable original prefit and new evaluation manifest. Original checkpoints do not contain invented matrix/metadata creation hashes. Reconstruct the full target matrix for one canonical predictor call, bound independent column-contribution arithmetic within 1e-9, and preserve canonical exact ties. Independent lexical original-truth decisions check component/dataset identities and complete unique context/direction rosters. Recheck all 42 reused predictors and source-only selections; save distinct new results and never overwrite original files. One numerical thread, no fitting, extraction, download or protected-outcome access.

The additive verifier also replays all 42 current original crossed-state target predictions/choices/configurations with these same checkpoints. An old unhashed verification PASS alone does not establish current identical predictors in both states. No original file is changed.

Commands after separate root authorization and completion of prerequisites: freeze, commit, evaluate --root-start, verify, gate, contrast, canonical_paired_contrast. Metadata readiness or synthetic passes alone do not authorize evaluation.
