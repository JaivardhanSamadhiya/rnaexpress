## Fixed models, objective and matched penalties

All arms use the same102 columns, source rows and original outcome-blind capped pair sampler: original context-specific seed20260927, unordered pairs without replacement, cap256, then omit exact truth-tied preferences. Reuse one roster across arms. Do not change the sampler, select favorable edits or filter sparse/noisy outcomes. Each source context must have a valid preference; an unexpected uninformative context is an admission failure rather than a new outcome-based cohort. All targets retain their complete menus and finite informative effect spans; an unexpected violation stops the experiment.

For each valid source pair p, y_p is sign(effect_left-effect_right). Let c_p=+1 for CAD and−1 for literal Neuro-2a. Weights are equal cell, equal component within cell, equal context within component/cell, equal valid sampled preference within context. Each cell has total mass1/2 and the total is1. This explicitly targets equal-cell/equal-component choice and is not a claim of bitwise equality to the old pooled study weights when unmatched menus are present.

Compute ONE common training-pair RMS per column using these weights and train rows only; active columns have RMS>=1e-8. Freeze every coefficient on an unsupported column exactly0 for all arms. Use the same common scale for the independent heads, rather than their cell-specific scales. A common weighted training-candidate mean may be subtracted for canonical score calculation, with candidate weights following the same cell/component/context/candidate hierarchy; it cancels in pair differences. Its exact future implementation must be frozen. The objective below uses z_p=(x_left-x_right)/RMS and no ranking intercept.

Pooled: sum_p w_p log(1+exp(-y_p z_p·beta)) + lambda/2 ||beta||².

Independent: each cell minimizes its conditional loss with weights2w_p and lambda/2 ||u_cell||². Equivalently the global objective is the half-weighted sum of the two cell objectives, with regularizer lambda/4 (||u_CAD||²+||u_N2A||²).

Joint_shrink10: sum_p w_p log(1+exp(-y_p z_p·(beta+c_p delta))) + lambda/2 (||beta||²+10||delta||²).

This ±1 coding removes an unconstrained shared/deviation redundancy. At multiplier1, u_CAD=beta+delta and u_N2A=beta−delta give exactly the independent objective, since ||u_CAD||²+||u_N2A||²=2(||beta||²+||delta||²). The invented checks verify objective values, gradient transformation, conditional-cell weight normalization and finite differences without any optimizer. At delta0 the joint objective is the pooled objective. Multiplier10 is fixed now; no multiplier search or cell-expression substitution is allowed.
