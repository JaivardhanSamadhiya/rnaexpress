# Small-edit inventory scope — before performance calculations

The new user request makes prediction of measured parent-to-mutant localization
change primary. This is a separately named reanalysis of already-exposed data.
It does not replace an old gate, reopen a failed experiment or create independent
confirmation. Inventory and source semantics precede any new performance scoring.

Read only the certified Phase-A/Phase-B Mikl, Moffatt and TDP localization
records; admitted SRLE scores/predictions; and SIRLOIN discovery replicate1/2
for its 227 already-evaluated SNVs and their two references. Read source manifests
and existing inventory/reports for other resources. Do not load reserved data,
N-zip, Astrocyte, TDP stability, or outcomes from unadmitted resources. Mikl's
paired raw delta fields may support repeatability; its stability columns are not
read. Preserve unknown absolute parent values as missing, with the documented
paired/reference-normalized effect carried separately.

Compute unit-cost global Levenshtein distance and one deterministic optimal
alignment with RapidFuzz. For equal-length experimentally aligned replacements,
also compute exact coordinate-wise changed bases (Hamming count). Primary small-
edit tiers use observed coordinate substitutions: Tier1 exactly one substitution;
Tier2 two or three changed bases; Tier3 four to six. Display span separately:
changes spread over a long sequence are not called localized six-base edits.
Minimum alignment distance is an additional table, not a way to relabel a larger
physical replacement as small. Alignment operations need not be unique or describe
the laboratory construction. Preserve source operation class/size separately.

Count distinct parent-mutant constructs separately from repeated cell/reporter
measurements, unique parents, genes and assay contexts. SRLE six-mer parents are
candidate anchors inside one shared HBB reporter experiment, not independent
parent genes. SRLE swaps have two changed positions, not one changed base.
Inventory measured swap neighbors only; generate no unmeasured RNA designs.

Exact same-sequence/control rows stay explicitly identified and are not edited
examples. All outcome-dependent eligibility and previous exposures are disclosed.
No new external discovery is attempted; the prior discovery review remains blocked.
