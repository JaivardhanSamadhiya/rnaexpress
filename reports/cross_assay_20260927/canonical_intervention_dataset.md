# Canonical edit dataset

`artifacts/cross_assay_20260927/canonical_interventions.csv` is the full 1–6-substitution inventory; its deterministic gzip copy is committed. The raw CSV and feature NPZ stay local with hashes in the evidence manifest. Larger edits are counted in `full_exposed_inventory_counts.csv` but are not silently treated as small edits.

Rows carry study/assay/cell/reporter/destination, exact parent and mutant sequence/IDs, context and gene, 1-based inclusive changed-coordinate bounds, changed-base count, separate minimum Levenshtein distance, physical span, paired ±10-nt local windows, measured parent/mutant values when actually available, paired effect, replicate descriptions/deltas, provenance/exposure, admission and candidate eligibility. Missing absolute measurements are NaN, never a measured zero. SRLE's available sequence is a six-mer inserted in a fixed HBB reporter, not a reconstructed full-length transcript.

`within_parent_rank` maps the lowest average tie rank to 0 and the highest to 1; a constant or singleton target has no defined ranking and stays ineligible. `normalized_delta` is effect divided by the within-context effect standard deviation, preserving the WT zero; it is secondary and not pooled as a universal raw effect. Canonical `desired_direction=+1` denotes increasing the stated destination. Decreasing uses reversed scores/ranks and negated measured effect. Evaluation emits both directions. Ratio-scale SIRLOIN and log-scale studies are never numerically pooled in the rank loss.

All candidate pairs within a context have the implicit preference `sign(delta_A-delta_B)`. Exact truth ties carry no ordering preference; prediction ties get half credit. Training uses all pairs for small sets and 256 uniformly sampled unordered pairs for larger sets, fixed by a context-derived hash seed without consulting outcomes. This is an approximation to the full pairwise objective, disclosed to avoid materializing millions of dependent pairs. Evaluation computes ordering accuracy over every pair, not the training sample. Parent/assay weights prevent saturated libraries from dominating.

Core training/evaluation: 26,258 measurements across four studies. Canonical inventory additionally retains secondary and singleton rows and their exclusion status. `model_row_index.csv` links every feature row to its canonical intervention. `features.npz` preserves raw feature vectors; each fit preserves training-only feature means/scales, shared/residual coefficients and membership. Thus normalized features and each prediction can be reconstructed without duplicating long sequences per model.

Connected components merge shared case-normalized gene labels and every exact parent/alternate-allele match, including across studies and repeated reporters. SRLE is one reporter component. Astrocyte's overlapping parents are conservatively grouped by gene, stronger than its prior five-component analysis. Three deterministic component folds support held-parent development where multiple training components exist; SRLE held-parent evaluation is explicitly ineligible.

Source exposure is irreversible. No newly unexposed measurement, reserved replicate or quarantined resource is included. The dataset recipe and all input/output hashes are part of the pre-comparison freeze.
