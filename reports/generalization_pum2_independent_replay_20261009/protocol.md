# Independent PUM2 feature replay
Freeze before comparing biological production features. This implementation reads the four pinned public parameter CSVs independently and uses nine direct contact coordinates, explicit coupling permissions and math.fsum of ordinary exp(-energy/RT) weights. It imports no producer energy, state enumeration, partition or parameter helpers. Synthetic tests may import production only to compare invented sequences.

All 4,070 admitted 140nt fragment sequences and all four operators must replay, including source row/ID/sequence hashes, parameter hashes, unique register keys, state counts and 4,054 mutant-minus-parent deltas. Absolute tolerance 1e-10 is fixed before production comparisons. Every state contributes once; retained sequences are never deduplicated. Conditional entire ninth-position terms and documented released/truncated coupling differences remain. 25 C is fixed. This is root's separate arithmetic implementation in the same bundled runtime, not execution by an independent laboratory or agent.

Fresh available RAM must remain >=3 GiB before production replay and each background. No labels or fitted models are read. No training or localization admission results from numerical replay alone.

Source: [Jarmoskaite 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6645366/).
