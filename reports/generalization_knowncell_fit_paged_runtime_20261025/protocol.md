software certificates, actual-owner requirements, static/current-proof
separation, 63 checkpoint-refresh positions and fail-closed phase ordering.

invented mocks, and source preparation imports no scientific package.

Native origin proofs, phases, same software objects and all 63 checkpoint refreshes remain unchanged.
